### Entity Model Features compatibility

Player Animation Library and bendable-cuboids remain required. Minecraft
1.21.1 includes default EMF definitions for the normal and slim player models
and inner/outer armor. These defaults retain the original model geometry and
UVs, so a separate EmoteBend resource pack is not needed for these models.

Custom CEM resource packs keep EMF's normal pack priority. EMF and ETF remain
optional; install them together according to EMF's requirements when using CEM
models. PAL animation coordination continues to use EMF's native integration.

### Entity Model Features 兼容

Player Animation Library 和 bendable-cuboids 仍是必需依赖。Minecraft 1.21.1
内置普通／纤细玩家以及内／外层盔甲的默认 EMF 定义，保留原模型几何和 UV，
这些模型无需再安装 EmoteBend 资源包。

自定义 CEM 资源包继续遵循 EMF 原有的包优先级。EMF 和 ETF 均为可选模组；
使用 CEM 模型时，请按 EMF 的要求一起安装。PAL 动画协同使用 EMF 的原生接入。
